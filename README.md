# railroad-designer

架空の鉄道路線の線形設計（平面線形・縦断線形）と、走行時間の計算のプログラムです。結果は確認用ページで、地図と縦断面図で見られます。

- 確認用ページ：https://hinoharu.github.io/railroad-designer/
- 対象：作者が作図した架空の路線（択捉島・国後島）。実在の路線の計画とは関係ありません。

## 中身
| フォルダ | 内容 |
|---|---|
| `kp/` | 計算の本体（Python）。作図の折れ線から、経路・平面線形（交点法）・地盤・縦断（線形計画法）・系統の走行を計算する。入力表は `kp/tables/` |
| `export/` | 駅レーダーサイトへ渡すファイル（路線の形と駅の位置の GeoJSON、補足の JSON）。形の決まりは `docs/exchange.md` |
| `page/` | 確認用ページとそのデータ |
| `docs/` | 仕様と判断の経緯 |

## データの出典
- 地形の標高：国土地理院 標高タイル（DEM10B）。地図の表示：地理院タイル。
- 作図した路線・駅：作者によるもの。
